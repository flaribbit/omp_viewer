# OMP Viewer

本项目用来解决自己遇到的两个问题：
- omp 终端渲染 LaTeX 还是有点太抽象了
- ssh 远程访问时，没法直接在终端里粘贴图片

## 运行

虽然项目是用 uv 创建的，但实际上只用到了标准库，不需要任何依赖。直接：

```bash
python main.py
```

然后浏览器打开：

```text
http://localhost:1416
```

命令行参数：

```bash
python main.py --host 127.0.0.1 --port 1416
python main.py --sessions-dir /path/to/sessions
```

查看器中“目录”右侧的“刷新”按钮会重新读取会话列表和当前会话内容，并在刷新完成后将消息滚动到底部。选择会话加载完成后也会滚动到底部。点击目录项目时会立即定位，不使用滚动动画。

## 上传图片

点击左侧的“上传图片”打开对话框，支持：

- 选择一张或多张图片
- 在对话框中按 `Ctrl+V` 粘贴图片
- 一次粘贴多张图片
- 一键复制所有已上传图片的 CLI 路径

复制结果示例：

```text
@/tmp/omp/00.jpg @/tmp/omp/01.png
```

图片保存在当前系统的临时目录下：

- Linux/macOS：`/tmp/omp`
- Windows：`%TEMP%\\omp`

上传文件名从 `00` 计数到 `99`，之后回到 `00`。重复编号会覆盖之前的文件。单张图片最大 20 MB。对话框中的“删除”只会移除当前列表项和复制路径，不会删除磁盘上的图片文件。临时文件的清理由系统或用户环境负责。
